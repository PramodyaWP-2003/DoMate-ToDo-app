# 📱 DoMate – ToDo Mobile Application

**Organize your tasks. Manage your time. Stay productive.**

## 📌 Project Overview

DoMate is a fully developed Android ToDo application designed to help users organize their daily tasks, manage responsibilities, and improve productivity through a simple, modern, and user-friendly interface.

The application was designed using Figma and developed using Java in Android Studio. This project demonstrates my practical skills in UI/UX design, mobile application development, and transforming design concepts into a functional mobile application.

## ✨ Key Highlights

- Modern and user-friendly interface
- Daily task management
- Clean and consistent UI design
- Simple and intuitive navigation
- Native Android application development
- Figma design-to-development workflow
- Focus on usability and user experience

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project using Android Studio.
3. Allow Gradle to synchronize the project dependencies.
4. Connect an Android device or start an Android emulator.
5. Build and run the application.
